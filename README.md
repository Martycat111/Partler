# Summary
A parts finding/organising web app,  
check in, out and view stock easily.  

This only for now, don't expect (or even hope for) rapid development.  
Thanks for trying out my project!  

# Quick-Start:

# Software
- Python 3.14

## Python requirements
+ Bottle
+ Sqlmodel

# Useage
Check in parts by adding new types,  
and/or add the amount you have.  

Once you want to use the parts (or don't have them anymore),  
check them out.  

Before you start a project,  
check which parts you have with "view stock",  
and order only the ones you need.
