## Python requirements
+ Bottle
+ Tinydb

# Self hosting
You can self host on basically any linux device with these 3 commands:
```
git clone https://github.com/Martycat111/Partler/
cd Partler
python3 main.py
```
It will then ask for a name for initial db setup.
# Usage
Check in parts by adding new types,  
and/or add the amount you have.  

Once you want to use the parts (or don't have them anymore),  
check them out.  

Before you start a project,  
check which parts you have with "view stock",  
and order only the ones you need.
